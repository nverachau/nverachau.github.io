# N Vera Chau — website draft

This branch holds a draft of the static website. GitHub Pages has not been enabled and the custom domain has not been changed.

## Preview locally

Run `python scripts/preview_server.py`, then open http://127.0.0.1:8000/.

## Update safely

Make edits and review the local preview before uploading. Upload only approved pages and their referenced assets; do not upload incoming ZIPs, temporary folders, Dropbox conflict copies, or shelved research.

The repository is public, so draft files are publicly readable even though the website is not deployed. A draft branch is not private storage.

Publishing and domain configuration require a separate launch decision. Do not enable Pages or change DNS as part of routine draft updates.
